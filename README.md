# MS VPN Bot (MHPanel Integration)

ربات تلگرام هوشمند و چندپروتکله برای مدیریت، فروش و اشتراک‌گذاری سرویس‌های VPN با اتصال مستقیم به API پنل **MHPanel**.

---

## 🌟 قابلیت‌ها و ویژگی‌های کلیدی

### ۱. پشتیبانی از طیف گسترده پروتکل‌ها
- **پروتکل‌های مبتنی بر Sing-box**: شامل VLESS (Reality), VMess, Trojan, ShadowSocks, TUIC v5, Hysteria 2.
- **پروتکل‌های سیستمی و استاندارد**: Cisco AnyConnect (OpenConnect), OpenVPN (دانلود خودکار فایل `.ovpn`), L2TP/IPsec, IKEv2, SSH Tunnel مستقیم, SSTP.
- **تانل‌های DNS و ضد سانسور**: پشتیبانی از تانل‌های SlowDNS (DNSTT), VayDNS, Slipstream QUIC, MasterDNS, NoizDNS, DoH, پل‌های Tor obfs4 و تولید لینک‌های استاندارد `slipnet://`.
- **وایرگارد (WireGuard)**: صدور خودکار کانفیگ و پیرهای اختصاصی WireGuard با فایل `.conf`.
- **Google Apps Script & Cloudflare Workers**: اتصال به ویزارد استقرار خودکار و تولید پروفایل‌های کلاینت.

### ۲. سیستم فروشگاه و مالی
- **دسته‌بندی‌های پویا**: امکان تعریف بی‌نهایت دسته‌بندی و پلن‌های مختلف با تعیین حجم، مدت زمان و قیمت.
- **کیف پول داخلی**: قابلیت افزایش موجودی و خرید مستقیم از موجودی کیف پول.
- **پرداخت کارت به کارت**: ارسال تصویر فیش بانکی توسط کاربر و تأیید/رد سریع توسط ادمین در تلگرام.
- **مدیریت کارت‌های بانکی**: افزودن، فعال‌سازی یا غیرفعال‌سازی چندین شماره کارت بانکی.

### ۳. پنل مدیریت حرفه‌ای در تلگرام
- **آمار و داشبورد زنده**: مشاهده تعداد کل کاربران، تراکنش‌ها، تیکت‌ها و اشتراک‌های فعال.
- **مدیریت کاربران**: جستجو بر اساس آیدی یا نام کاربری، تغییر موجودی، مسدودسازی.
- **ارسال پیام همگانی**: ارسال اطلاعیه به تمامی اعضای ربات با فرمت HTML.
- **تنظیمات سیستم**: تغییر مشخصات سرور، درصد رفرال، حجم و مدت زمان اکانت تست مستقیم از بات.

### ۴. امکانات کاربری
- **اکانت تست رایگان**: دریافت یکبار اکانت تست خودکار جهت بررسی کیفیت اتصال.
- **سیستم بازاریابی و زیرمجموعه‌گیری (Referral)**: لینک اختصاصی و دریافت پورسانت درصدی در کیف پول.
- **سیستم تیکت و پشتیبانی**: ارسال تیکت و پیگیری پاسخ‌ها درون ربات.
- **آموزش و دانلود کلاینت‌ها**: لینک‌های دانلود رسمی نرم‌افزارهای اندروید، iOS، ویندوز و راهنمای گام به گام اتصال.

## 🚀 راهنمای نصب سریع

### روش اول: اسکریپت نصب خودکار (پیشنهادی)

```bash
git clone https://github.com/t-51/MS_VPN_BOT.git /opt/ms-vpn-bot
cd /opt/ms-vpn-bot
chmod +x install.sh
./install.sh install
```

### روش دوم: اجرا با داکر (Docker Compose)

```bash
cp .env.example .env
nano .env
docker compose up -d
```

---

## ⚙️ متغیرهای محیطی (.env)

| متغیر | توضیحات |
|---|---|
| `TELEGRAM_TOKEN` | توکن ربات از @BotFather |
| `BOT_USERNAME` | یوزرنیم ربات بدون @ |
| `PANEL_API_KEY` | کلید API پنل MHPanel |
| `PANEL_API_URL` | آدرس پایه API پنل (مثال: `https://panel.example.com/api`) |
| `ADMIN_ID` | شناسه عددی تلگرام مدیر ربات |
| `SERVER_IP` | آی‌پی عمومی سرور |
| `CARD_NUMBER` | شماره کارت جهت دریافت مبالغ |
| `TRIAL_TRAFFIC_GB` | حجم اکانت تستی (گیگابایت) |
| `TRIAL_DURATION_DAYS` | مدت زمان اکانت تستی (روز) |

## 🛠 ابزارهای مدیریت ربات

پس از نصب، می‌توانید با دستور زیر منوی مدیریتی ربات را فراخوانی کنید:

```bash
./install.sh
```

گزینه‌های در دسترس:
- مشاهده وضعیت سرویس (Status)
- راه‌اندازی مجدد (Restart)
- مشاهده لاگ‌های زنده (Logs)
- ویرایش فایل تنظیمات (.env)
- به‌روزرسانی خودکار سورس کد (Update)
- حذف کامل سرویس (Uninstall)
